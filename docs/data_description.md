# Описание данных проекта (блок 8)

## 1. База знаний

Файл: `data/documents.json`.

Это учебная вымышленная база знаний из ноутбука блока 8. Она не является
официальным регламентом организации.

Формат: JSON-массив объектов.

| Поле | Тип | Назначение |
|---|---|---|
| `id` | string | код источника: `D01`…`D16`, `STUDENT` |
| `title` | string | название документа |
| `text` | string | текст документа (1–2 абзаца) |

Документы `D01`–`D16` взяты из ноутбука. `STUDENT` — собственный
документ экзаменационной работы: он описывает правила запуска
консольного помощника, флаг `--ask`, сохранение результатов и запрет
на публикацию секретов.

Ограничения:

- тексты короткие (примерно 360–650 символов);
- база знаний маленькая, поэтому метрики поиска могут быть высокими;
- документы не содержат персональных данных и секретов.

## 2. Контрольные вопросы

Файл: `data/check_questions.json`.

Формат: JSON-массив объектов.

| Поле | Тип | Назначение |
|---|---|---|
| `question` | string | вопрос своими словами |
| `expected` | string | код документа, где находится ответ |

Содержится 32 вопроса из ноутбука и 1 собственный вопрос к документу
`STUDENT`. По этой таблице считаются метрики:

- **Top-1 accuracy** — ожидаемый документ оказался первым;
- **Hit@K** — ожидаемый документ попал в первые K разных источников.

## 3. Чанки

Чанк — фрагмент документа, полученный разбиением по словам.

- `chunk_size` — приблизительный размер чанка в символах;
- `overlap` — приблизительное повторение символов на границе.

При рабочих параметрах `chunk_size=230`, `overlap=30` получается
47 чанков на 17 документов.

## 4. Эксперименты

| Код | Чанк | Overlap | Поиск | Top-K | Идея |
|---|---|---:|---|---:|---|
| A | 380 | 45 | word | 1 | базовый поиск по словам |
| B | 380 | 45 | char_wb | 2 | поиск по группам букв |
| C | 200 | 30 | char_wb | 3 | короткие чанки |
| D | 700 | 100 | char_wb | 3 | длинные чанки |
| E | 300 | 0 | word | 5 | свой опыт: без перекрытия, много источников |

## 5. Артефакты

В `reports/` сохраняются:

- `experiments.csv` — сводка пяти опытов;
- `retrieval_check.csv` — проверка каждого контрольного вопроса;
- `settings.json` — параметры запуска;
- `demo_answer.txt`, `custom_answer.txt`, `no_answer.txt` — примеры ответов;
- `final_report.md` — итоговый отчёт;
- `charts/*.png` — графики Top-1 / Hit@K и числа чанков.

## 6. Секреты

В проекте не используются API-ключи, токены и пароли. Файлы `.env`
исключены из Git. В демонстрационных вопросах нет персональных данных.
