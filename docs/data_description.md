# Описание данных проекта (блок 8)

Единственный источник данных — база знаний `D:\study\handbook`.
Путь можно переопределить переменной окружения `HANDBOOK_DIR`.

## 1. Что входит в корпус

- `README.md` и тематические `01-python.md` … `11-karta-istochnikov.md`;
- `konspekty/*.md` — конспекты ноутбуков;
- `istochniki/**/*.docx` — Word-документы по блокам.

Текущая сборка: **77 документов** (20 md + 57 docx), **~167 тыс. слов**.

Сборка:

```bash
python main.py --build-corpus
```

Результат: `data/handbook_documents.json`, статистика
`reports/handbook_corpus_stats.json`.

## 2. Схема документа

Формат: JSON-массив объектов.

| Поле | Тип | Назначение |
|---|---|---|
| `id` | string | относительный путь без расширения, например `konspekty/ml` |
| `title` | string | заголовок или имя файла |
| `text` | string | извлечённый текст |
| `source_path` | string | путь внутри `handbook` |
| `category` | string | `handbook`, `konspekt` или `source` |
| `block` | string | учебный блок или имя конспекта |
| `kind` | string | `md` или `docx` |
| `language` | string | `ru`, `en` или `mix` |
| `chars` | int | число символов |
| `words` | int | число слов |
| `hash` | string | SHA1 нормализованного текста для дедупликации |

## 3. Фильтрация и приватность

- точные дубли удаляются по хэшу содержимого;
- файлы с именами вроде `Экспорт_чата`, `Доступы`, `pwd`, `password`,
  `token`, `secret` исключаются;
- личные заметки и служебные файлы не включаются;
- PDF, изображения, архивы и сырые данные не включаются;
- полный текст корпуса не коммитится в Git.

## 4. Контрольные вопросы

Файл: `data/handbook_check_questions.json`, **50 вопросов**.

| Поле | Назначение |
|---|---|
| `question` | вопрос своими словами |
| `expected` | строка или список допустимых источников |

Список допустимых источников нужен потому, что один и тот же ответ часто
есть в конспекте, первоисточнике и глоссарии.

Метрики:

- **Top-1** — первый найденный документ входит в список правильных;
- **Hit@K** — хотя бы один правильный документ попал в первые K.

## 5. Параметры и результат

| Параметр | Значение |
|---|---:|
| `CHUNK_SIZE` | 600 |
| `OVERLAP` | 100 |
| `SEARCH_METHOD` | `char_wb` |
| `TOP_K` | 3 |

При этих настройках: **2583 чанка**, **Top-1 = 0.720**,
**Hit@K = 1.000** на 50 вопросах.

## 6. Артефакты

В `reports/handbook/` сохраняются:

- `experiments.csv` — сводка пяти опытов;
- `retrieval_check.csv` — проверка каждого вопроса;
- `settings.json` — параметры запуска;
- `demo_answer.txt`, `custom_answer.txt`, `no_answer.txt` — примеры ответов;
- `final_report.md` — итоговый отчёт;
- `charts/*.png` — графики Top-1 / Hit@K и числа чанков.

Статистика сборки корпуса: `reports/handbook_corpus_stats.json`.

## 7. Секреты

В проекте не используются API-ключи, токены и пароли. Файлы `.env`
исключены из Git. В демонстрационных вопросах нет персональных данных.
